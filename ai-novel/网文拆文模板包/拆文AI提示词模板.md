# 网文拆文 AI 提示词模板

配合《网文拆文工作表.xlsx》使用。整体流程：把小说内容分批喂给 AI → AI 按下面的提示词输出结构化表格 → 复制粘贴进 Excel 对应工作表 → 由「节奏统计」表自动生成分析结果。

> **粘贴小技巧**：AI 输出的是 Markdown 表格，直接复制到 Excel 单元格时可能整段挤进一格。选中粘贴区域后用「数据 → 分列」，以 `|` 作为分隔符，即可自动拆成多列；也可以在提示词末尾加一句"请改为按 Tab 分隔的纯文本表格"，输出会更适合直接粘贴。

## 提示词模板 1：逐章拆解（核心，配合"逐章拆解"表）

**使用方法**：中长篇不要一次性丢全文。建议每次喂 5~10 章（约 1.5~3 万字），拆解完一批再拆下一批，避免 AI 因上下文过长而遗漏细节或记混设定。

```
你是一位专业的网文编辑，请对我提供的章节内容逐章拆解，用于后续的节奏和爽点分析。

【已知设定摘要】（如是第一批可留空，后续批次请把上一批AI生成的"设定摘要"贴在这里，保持人物和伏笔连贯）
{此处粘贴已知设定摘要}

【输出要求】
逐章输出一个 Markdown 表格，每章一行，列如下，严格按顺序：
章节号 | 章节标题 | 字数 | 所属阶段/卷 | 核心事件（一句话，30字以内）| 新增角色 | 伏笔埋设 | 伏笔回收 | 爽点/反转类型 | 情绪标签 | 结尾钩子 | 备注

【字段规则，必须遵守】
- “所属阶段/卷”：先给出你判断的阶段名称（如“开篇建置”），若不确定就填“待定”。
- “伏笔埋设”“伏笔回收”：没有就留空，不要写“无”。
- “爽点/反转类型”：只能从以下选项中选一个，不确定选“无”：
  打脸 / 逆袭 / 身份揭露 / 危机反转 / 情感高光 / 能力突破 / 阴谋算计 / 悬念揭晓 / 无
- “情绪标签”：只能从以下选项中选一个：
  甜 / 虐 / 爽 / 虐后甜 / 紧张 / 治愈 / 搞笑 / 热血 / 平淡
- “结尾钩子”：只能从以下选项中选一个：
  悬念 / 危机 / 反转 / 情感冲击 / 信息量炸弹 / 无
- 不要编造原文没有的情节，不确定的字段填“待定”而不是猜测。

表格输出完后，再单独给我一份【设定摘要】（150字以内），包含：目前的人物状态、未回收的伏笔清单、当前阶段的核心目标。我会在喂下一批章节时把这份摘要交还给你。

以下是本批章节内容：
{此处粘贴5~10章正文}
```

## 提示词模板 2：结构总览生成（配合"结构总览"表）

**使用方法**：适合在积累了一定量的逐章拆解表，或有完整目录/剧情简介后使用。

```
你是一位专业的网文编辑。以下是这本小说的章节目录/剧情简介，或是我已经逐章拆解出的事件列表。

请把全书划分为若干个阶段（如：开篇建置、发展铺垫、中期小高潮、转折、大高潮、回落、结局），输出一个 Markdown 表格，列如下：
序号 | 阶段/卷名 | 起始章节 | 结束章节 | 阶段功能 | 核心冲突 | 关键转折事件

要求：
- “阶段功能”只能从以下选项中选：开篇建置 / 发展铺垫 / 小高潮 / 转折 / 大高潮 / 回落 / 结局
- “核心冲突”“关键转折事件”各一句话概括，不超过40字
- 阶段划分依据明显的情节转折点（如金手指觉醒、身份暴露、感情线突破、最终决战等），不要机械按章节数平均切分

以下是内容：
{此处粘贴目录/简介/已拆解的事件列表}
```

## 提示词模板 3：人物卡生成（配合"人物卡"表）

```
你是一位专业的网文编辑。请根据以下内容，为出现的主要角色（主角 + 重要配角，忽略纯打酱油角色）生成人物卡，输出 Markdown 表格：
角色姓名 | 身份/阵营 | 首次登场章节 | 核心目标/动机 | 弧线起点 | 弧线终点 | 与主角关系 | 重要程度 | 备注

要求：
- “弧线起点”“弧线终点”各用一句话概括该角色从故事开始到（目前为止/结局）的状态变化
- “重要程度”只能从以下选项中选：主角 / 核心配角 / 次要配角 / 工具人 / 反派
- 只输出确实反复出现、对剧情有推动作用的角色，不要凑数

以下是内容：
{此处粘贴已拆解的章节事件，或人物相关的原文片段}
```

## 提示词模板 4：卖点/简介提炼（配合"卖点提炼"表）

**使用方法**：建议在完成逐章拆解和结构总览之后使用，这样 AI 有足够信息判断全书的核心卖点。

```
你是一位网文平台的资深责编，擅长写爆款简介和推荐语。请根据以下拆解内容，帮我提炼：

1. 一句话简介（30字以内，突出反差和冲突）
2. 三句话简介（分别对应：起因/困境、转折/金手指、目标/爽点方向）
3. 核心冲突关键词（3~5个）
4. 金手指/设定亮点（一句话说清它如何和爽点绑定）
5. CP/关系看点（如有）
6. 适合对标的同类型作品方向（不点评具体书名的优劣，只说风格相似点）
7. 目标读者画像
8. 更适合的呈现载体（原著连载 / 短剧改编 / 广播剧等），并说明理由

以下是我的拆解内容（结构总览 + 部分逐章事件）：
{此处粘贴"结构总览"表内容 + 关键章节事件}
```

## 拆长篇时如何避免 AI"遗忘"设定

中长篇一次性喂给 AI 容易导致人物、伏笔记混，建议：

1. **分批 + 滚动摘要**：严格按模板1的流程，每批结束都让 AI 产出"设定摘要"，下一批开头带上，相当于给 AI 一份"记忆卡"。
2. **控制单批长度**：单次 5~10 章、1.5~3万字比较稳妥，太长容易漏拆或张冠李戴。
3. **抽样而非全量**：如果只是想学节奏、写简介，不需要每一章都拆——可以拆黄金三章、每卷开头结尾、几个公认的高潮章节，够用即可，没必要硬拆完1000+章。
4. **定期人工抽查**：每拆完3~5批，抽1~2章回去对照原文，确认 AI 没有编造情节或记混人物关系。

## 注意事项

- AI 拆解只是辅助草稿，人物设定、关键情节请务必人工核对后再定稿。
- 若拆解结果用于自己的创作或商用改编，情节、人设、台词需要重新原创化表达，避免和原作过于雷同的抄袭风险。
- 涉及具体台词/原文的引用要谨慎，拆解应该输出"事件摘要"而不是照抄整段原文。
