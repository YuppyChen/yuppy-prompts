# yuppy-prompts

个人整理的 AI 提示词（系统提示 / 元提示）仓库，按主题分目录存放，便于复制到对话或工作流中使用。

## 目录结构

| 路径 | 说明 |
|------|------|
| [`suno/`](suno/) | 面向 Suno、Udio 等 AI 音乐生成场景的提示词 |
| [`gpt-image-2/`](gpt-image-2/) | 面向 GPT Image 生成与图文设计场景的提示词 |

## `suno/` 文件一览

| 文件 | 用途简述 |
|------|----------|
| [向阳乔木.md](suno/向阳乔木.md) | Suno AI 歌词创作：从用户输入到结构化歌词与技法说明 |
| [归藏大佬.md](suno/归藏大佬.md) | AI 音乐提示词工程师：按歌手与歌词输出全局风格 + 分段指令 |

## `gpt-image-2/` 文件一览

| 文件 | 用途简述 |
|------|----------|
| [拆解食物的一生.md](gpt-image-2/拆解食物的一生.md) | 食物主题的分镜/阶段拆解图解提示词 |
| [治愈系手账学科知识图解.md](gpt-image-2/治愈系手账学科知识图解.md) | 治愈系手账风格的学科知识可视化提示词 |
| [伊索寓言手抄报.md](gpt-image-2/伊索寓言手抄报.md) | 寓言故事主题手抄报版式与画面提示词 |
| [健康养生知识卡片.md](gpt-image-2/健康养生知识卡片.md) | 养生信息卡片化呈现与视觉规范提示词 |
| [寓言故事学习概念.md](gpt-image-2/寓言故事学习概念.md) | 寓言学习类概念图与教学素材提示词 |

各 Markdown 文件顶部含 **元提示**（作者、来源链接），引用时请保留以便溯源。

## 使用方式

1. 打开对应 `.md` 全文复制为系统提示，或只复制你需要的章节。
2. 在对话中说明你的具体需求（主题、歌手、歌词片段等），再粘贴提示词模板。
